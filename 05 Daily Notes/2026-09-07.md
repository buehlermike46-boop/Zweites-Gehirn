## Entscheidungen
- Automatisierung läuft per Windows Scheduled Task + eigenem Python-Agent (Anthropic API direkt), nicht per Claude-Code-CLI im Hintergrund, weil auf diesem Rechner keine eigenständige Claude-Code-CLI installiert ist (nur die Desktop-App).
- Task-Agent bewusst ohne Zugriff auf E-Mail/Kalender/Zahlungen/Systemeinstellungen gebaut, nur Vault-Dateien + lesender Web-Zugriff, damit er unbeaufsichtigt laufen kann.
- Telegram-HAND-Baustein bewusst als zwei getrennte Systeme gebaut statt eins: Business-Bot (sicher, offiziell) und persönlicher Userbot (echte Chats, aber ToS-Risiko) haben unterschiedliche Risikoprofile und sollten nicht vermischt werden.
- Beide Telegram-Bausteine nach dem "Entwurf statt Auto-Antwort"-Prinzip gebaut — Mike möchte jede Antwort selbst sehen/freigeben, bevor sie rausgeht, nicht dass Jarvis eigenständig in seinem Namen antwortet.
- Hermes Agent NICHT an Telegram/Vault/Account angebunden (kein bestätigter Freigabe-Mechanismus, siehe oben) — bei den eigenen, bereits getesteten Systemen (3a/3b) geblieben.
