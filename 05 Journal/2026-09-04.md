# Tagesnotiz 04.09.2026

## Was heute passiert ist

**Automatisierung repariert**
- Bug gefunden und gefixt: Router-Zweig für "neues Mitglied" hatte keinen Filter, hat auf jedes Telegram-Update reagiert
- Problem gelöst: Alte "Start Now"-Nachricht wird jetzt automatisch gelöscht, bevor eine neue gepostet wird (Data Store speichert die letzte Message-ID) — kein Zumüllen des Gruppenchats mehr
- Stolperstein unterwegs: Make.com-Änderungen waren nicht automatisch gespeichert (Editor-Änderungen ≠ live), musste über "Recover unsaved changes" + "Save scenario" nachgeholt werden — Lehre fürs nächste Mal

**Neue Architektur: Kanal + Gruppe**
- Moritz' "Freedom Circle" als Vorbild angeschaut (Kanal + Start-Bot)
- Entscheidung: bestehende Gruppe "Limitless" bleibt erhalten, zusätzlich neuer Kanal erstellt
- Neuer öffentlicher Kanal **"Inner Circle - Mike Bühler"** (t.me/JointoInnerCircle) — eigene Marke, kein Bezug zu "Limitless" im Namen
- Bot als Administrator hinzugefügt, Willkommensnachricht mit echtem Inline-Button "🚀 Start Now" gepostet und angepinnt

**Rollen klar aufgeteilt**
- **Kanal** = Akquise/Top of Funnel: Content, Ergebnisse, Einblicke zeigen → Leute klicken Start → Konto erstellen
- **Gruppe** = Community nach Anmeldung: Signale austauschen, Live-Sessions, Austausch untereinander

**Bot-Onboarding-Text finalisiert**
- Aufbau angelehnt an Moritz' Start-Bot (dort reingeschaut), aber deutlich kompakter
