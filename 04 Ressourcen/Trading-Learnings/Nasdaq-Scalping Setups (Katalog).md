# Nasdaq-Scalping Setups (Übersicht)

Eigenes Kurskapitel für NQ-Scalping-Setups, aufbauend auf Indikatoren statt auf reinem Footprint/Delta wie bei den [[RangeUS Chart (Kontext für Setups)|RangeUS-Footprint-Setups]].

## Indikatoren (Bausteine)

- [[RG-Trading Indikator - ATR (Average True Range)]] — Volatilitätsmaß, Basis für Stop-Größen
- [[RG-Trading Indikator - Supertrend]] — Trendfolge-Ampel, baut auf ATR auf
- [[RG-Trading Indikator - Demand Index]] — Preis/Volumen-Frühindikator, wichtigster Bestätigungsfilter
- [[Heikin-Ashi Kerzen (Grundlagen)]] — geglättete Kerzendarstellung

## Gemeinsames Muster

Fast alle Setups kombinieren zwei bis drei Bestätigungsebenen: Kerzenstruktur (Lunten, Heikin-Ashi-Farbe/Docht) + Supertrend-Bruch + Demand-Index-Signal (Nulllinien-Kreuzung oder Divergenz). Je mehr Ebenen übereinstimmen, desto stärker das Signal.
