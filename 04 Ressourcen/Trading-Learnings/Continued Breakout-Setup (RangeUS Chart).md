# Continued Breakout-Setup (RangeUS Chart)

Trendfolge-Setup auf dem [[RangeUS Chart (Kontext für Setups)]]. Gegenstück zum [[Delta Reversal-Setup (RangeUS Chart)]]: hier wird **mit** der laufenden Bewegung gehandelt, nicht gegen sie.

## Marktzyklus-Kontext (Wyckoff-artig)

Bevor das Setup gehandelt wird, wird eingeordnet, in welcher Phase sich der Markt befindet:
Accumulation-Phase → Markup-Phase → Distribution-Phase → Marktdown-Phase → Re-Accumulation → Re-Distribution.

Das Setup wird typischerweise während der Markup-/Marktdown-Phase gehandelt, nach einer kurzen Konsolidierung (Re-Accumulation/Re-Distribution) als Fortsetzung des Trends.

## Setup-Kriterien (Breakout-Bestätigung)

Ein gültiger Breakout in Trendrichtung zeigt:
1. **Min Delta nahezu Null** (bei einer Aufwärtsbewegung: kaum Verkaufsdruck während der Kerze)
2. **Max Delta hoch** (starker Kaufdruck dominiert)
3. **Absorption** sichtbar (Gegenseite wird aufgesogen, ohne den Preis zu drehen)

In den Chartbeispielen wird eine Serie von Pfeilen/Kreisen gezeigt, die kleine Rücksetzer mit auffällig geringem Gegendelta markieren, jeweils gefolgt von Fortsetzung in Trendrichtung. Das ist das wiederkehrende Muster: kurzer Pullback mit schwachem Gegendelta → Fortsetzung.

## Verwandt

- [[Sammelzonen-Volumenberg Breakout-Setup (RangeUS Chart)]]: ähnliches Prinzip, aber Ausbruch aus einer klar erkennbaren Sammelzone/Volumenberg statt aus einem einfachen Pullback.
