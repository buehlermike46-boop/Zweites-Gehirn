# Sammelzonen-/Volumenberg Breakout-Setup (RangeUS Chart)

Breakout-Setup auf dem [[RangeUS Chart (Kontext für Setups)]], nahe verwandt mit dem [[Continued Breakout-Setup (RangeUS Chart)]], aber mit Fokus auf eine sichtbare **Sammelzone** (enge Konsolidierung, oft direkt an VAL/VAH oder einem Volumenberg-Rand).

## Ablauf

1. Markt bewegt sich zu einer Location (z.B. VAL eines Volumenprofils) und bildet dort eine **enge Sammelzone**: mehrere kleine Kerzen in einer schmalen Range, sichtbar als Box im Chart.
2. Innerhalb der Sammelzone bleibt das Delta klein/unauffällig (kein starker Richtungsdruck), das ist Teil der Bestätigung, dass hier noch keine Entscheidung gefallen ist.
3. Der Ausbruch aus der Sammelzone in eine Richtung wird durch auffällige Delta-Prints an der Ausbruchskerze bestätigt (in den Chartbeispielen als Kreise markiert).
4. Einstieg in Ausbruchsrichtung, meist mit der übergeordneten Trendrichtung (siehe Kontext-Regeln in [[Tageskontext & Location - Analyse-Guides]]).

## Unterschied zum Continued Breakout-Setup

- Continued Breakout: kurzer Pullback mitten in einer laufenden Bewegung.
- Sammelzonen-/Volumenberg Breakout: längere, deutlich sichtbare Konsolidierungsbox an einer klaren Location (VAL/VAH/Volumenberg-Kante), nicht nur ein kurzer Rücksetzer.
