# NQ Abpraller-Setup Checkliste

Checkliste für das Abpraller-Setup im NQ, aufgebaut nach den 3 Säulen **Tageskontext → Location → Setup**.

## 1. Tageskontext (ES, M15)
- Inside Day? / Outside Day?
- **Regel 1 (höchste Priorität):** Vortageshoch/-tief abgelehnt oder akzeptiert? → Nur in Richtung der Ablehnung bzw. Annahme handeln.
- **Regel 2:** Trendtag? (neue Hochs/Tiefs/Volumenberge) → Nur mit dem Trend handeln.
- **Regel 3** (falls 1 & 2 nicht aktiv): Value Area / POC höher oder tiefer? → Long bei steigender Value, Short bei fallender Value.

## 2. Market Profile (ES, M30)
Balanced Day / Trend Balanced / Inside Day (+Breakout/Fake) / Vortages Fake / Single Prints (ungetestet? getestet? wichtige Reaktionszone?).

## 3. Location
Handel nur an einer A-Location: VAH, VAL, POC, HVN, LVN, Ober-/Unterkante Volumenberg, Single Prints, Vortageshoch/-tief, Tageshoch/-tief, Range High/Low.

## 4. Setup (NQ)
- **ES bestätigt?** ES reagiert an der Location, gleiche Richtung wie NQ.
- **Demand Index (NQ)** als letzter Bestätigungsfilter: Nulllinie & Durchschnittslinie in Trade-Richtung durchbrochen, keine Divergenz, zeigt wer den Markt dominiert.
- **5-Min Footprint (Abpraller-Setup):** Ablehnungskerze, MAX Delta nahe 0, hohes MIN Delta, Rücktest des POC, Delta wird negativ → Einstieg.
- **Range Chart (US):** Reversal an der Location, Trendwechsel sichtbar, keine späte Bewegung.
- **Orderflow:** Absorption/Iceberg, große LTQ, Delta bestätigt.

## 5. Trade Management (vor Einstieg)
Stop logisch, erstes Ziel definiert, CRV mind. 1:2, Risiko eingehalten, kein emotionaler Einstieg.

## 6. Nur wenn ALLES erfüllt ist
Tageskontext ✅ Market Profile ✅ Location ✅ ES bestätigt ✅ Footprint ✅ Orderflow ✅ NQ zeigt Reversal ✅ → Einstieg.

## Entscheidungsbaum (Kurzform)
Tageskontext (ES M15) → Market Profile (ES M30) → Location → Bestätigung (ES + NQ synchron, Footprint, Delta, Orderflow) → Einstieg (Risiko/Ziel passt) → Trade.

## Reihenfolge-Prinzip
Immer grob → fein vorgehen, damit kein gutes Footprint-Signal gehandelt wird, obwohl Tageskontext oder Location eigentlich dagegensprechen.
